Stockify CORS Test

這是一個最小測試頁，用瀏覽器直接 `fetch` 外部股票頁面或 API。 如果目標站台沒有開 CORS，結果會直接顯示被瀏覽器擋下。

測試目標

建議用本機 HTTP 伺服器或 GitHub Pages 開啟，不要直接用 `file://`。 `file://` 會讓 origin 變得更混亂，不利於判斷到底是 CORS、CSP，還是檔案協定本身的限制。

說明

  • 這頁只做最原始的瀏覽器跨域檢查，不做任何代理或繞過。
  • 如果是 CORS 問題，瀏覽器通常會回傳 `TypeError: Failed to fetch` 或類似錯誤。
  • 如果可以抓到內容但不是 JSON，表示網頁可能允許跨域，但內容解析還要另外處理。
  • 如果某個站只有伺服器端可抓、前端抓不到，之後就需要後端 proxy 或桌面原生層來做。
